# Simple Calculator – Qt Project

This is a simple calculator application built using **Qt**.  
I created this project as a personal exercise to begin learning Qt and to get familiar with its structure, tools, and GUI programming model.  
It's not intended as a professional or complete application—just a small, meaningful step in my own programming journey.

## Features

- **Addition**: Adds two numbers.
- **Subtraction**: Subtracts one number from another.
- **Clear**: Clears the current input.

## Motivation

This project was part of my early exploration of Qt and C++ GUI development.  
I built it to understand key concepts like widgets, signals and slots, and layout management—not to deliver a polished product.  
It helped me take my first steps in creating interactive desktop applications.

## Installation

1. Clone or download the repository.
2. Open the project in **Qt Creator** or another Qt-compatible IDE.
3. Build and run the project.

## Requirements

- Qt 6.8 or newer
- A C++ compiler that works with Qt

## Usage

1. Run the application.
2. Use the on-screen buttons to enter numbers.
3. Click **+** or **-** to perform the operations.
4. Click **C** to clear the input.

## Reflection

While the app itself is very simple, working on it was valuable for me.  
It gave me confidence to start experimenting with Qt and showed me the basic structure of a GUI-based program.  
I plan to build more advanced applications as I continue learning.
